# Torkoal

`torkoal.png`: sprite pixel art frontal de Torkoal (Pokédex nº 324), PNG transparente de 96 × 96 píxeles. Se comparte entre el logo de TEAMLAB y el favicon.

Fuente: [PokéAPI Sprites](https://github.com/PokeAPI/sprites/blob/master/sprites/pokemon/324.png).

Pokémon y los gráficos originales pertenecen a sus respectivos titulares (Nintendo, Creatures y GAME FREAK). El archivo se conserva sin modificaciones.
